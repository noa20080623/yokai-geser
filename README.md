# 妖怪ゲッサー

妖怪ウォッチの妖怪の名前を当てる、友だち向けのファンゲームです。

- `index.html` 1枚で動きます（GitHub Pages でそのまま公開できます）
- ホーム画面に追加するとアプリのように使えます（PWA）

## 公開方法（GitHub Pages）

1. リポジトリの **Settings → Pages** を開く
2. Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
3. 数分後に `https://noa20080623.github.io/yokai-geser/` で遊べます
